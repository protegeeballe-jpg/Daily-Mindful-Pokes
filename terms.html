4. Data storage, encryption, and synchronization

The App keeps local application records in your browser and saves a compressed, AES-256-GCM encrypted daily packet in IndexedDB for synchronization and export. Each daily packet includes that date's checklist states (checked and unchecked), Diary and reflection records, encrypted voice-note records, location tags, and relevant Garden/progress state. The browser compresses the daily bundle before encrypting it. The Worker receives ciphertext, a Vault ID, a date, a Write Token header, and request metadata; it does not receive your passphrase or AES encryption key.

The account master key and raw Write Token exist in browser memory only. The session locks after 15 minutes of inactivity. Automatic synchronization is queued after five seconds without changes and is attempted when the page becomes hidden. A Durable Object coordinates writes and checks versions to reduce cross-device overwrites. When two devices edit the same date independently, the App may pause the update and preserve conflicting copies rather than choosing one automatically.

Some underlying checklist, progress, location, and Garden records in localStorage are not encrypted at rest by the App. The encrypted IndexedDB packet protects the synchronization copy and cloud copy, but it does not make every raw browser-storage record ciphertext. Anyone with access to your unlocked device or browser profile may be able to inspect those local records.

Location check-ins are included inside the encrypted daily packet. Their cloud copies are encrypted before transmission. The Health Checklist Reset preserves the main Diary, voice notes, and location history; it clears the selected date's checklist progress/reflections and restarts the Garden planting setup.

5. Local backup file

Settings provides an optional local JSON export/import of encrypted daily packets. Import requires signing in to the same account that created the file. Keep exported files secure because they contain encrypted personal information and date metadata. Export/import is a fallback and is not required for automatic cloud synchronization. Google Drive and GitHub Gist synchronization are not part of the current App.
